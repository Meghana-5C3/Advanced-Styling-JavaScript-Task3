# Advanced Styling and JavaScript - Task 3

## 🚀 Project Overview
This project demonstrates advanced CSS and JavaScript concepts by building a responsive and interactive web application.

The project includes:
- Responsive Web Design using Media Queries
- Interactive Image Carousel
- JavaScript Quiz Application
- API Data Fetching using Fetch API
